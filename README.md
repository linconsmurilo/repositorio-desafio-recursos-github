## Conversor de Temperatura em Python 🌡️
Outro projeto simples em Python para converter temperaturas entre as escalas Celsius (°C) e Fahrenheit (°F).

## Funcionalidades:
- Conversão de Celsius para Fahrenheit usando a fórmula: \(F=C\times 1.8+32\).
- Conversão de Fahrenheit para Celsius usando a fórmula: \(C=(F-32)\times 5/9\).

## Tecnologias Utilizadas:
- Python
